One support-queue dataset. Four different questions. Only one chart answers each cleanly.

Northgate Telecom's Tier-1 support queue logs the same 20 days: how many agents were on shift, issues flagged on calls by type, and one sampled call's handle time. Nothing about the data changes below — only the question does. Pick a question to see which tool it calls for, and why the other three fall short of it.
