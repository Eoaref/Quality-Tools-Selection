Quality tools — worked example

One shop-floor dataset. Four different questions. Only one chart answers each cleanly.

What this is for: to show that the tool you reach for should depend on the question you're asking, not on what the data happens to look like. The dataset below never changes — only the question does.

How to use it: start here and read through all four tabs. When you're ready, move on to the practice quiz — a low-stakes way to test whether the idea stuck.
